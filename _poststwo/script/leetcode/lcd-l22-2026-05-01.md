## PPT 3 — Essential Bit Operations

There are three operations every interview candidate should know.

AND:

```python
a & b
```

Used to check whether a bit is set.

OR:

```python
a | b
```

Used to turn a bit on.

XOR:

```python
a ^ b
```

Used to toggle bits and cancel duplicate values.

The most important XOR properties are:

```text
x ^ x = 0
x ^ 0 = x
```

These two rules power many interview solutions.

The key idea is:

**AND checks, OR sets, XOR cancels or toggles.**

## PPT 4 — Bit Masks

A bit mask is simply a number used to manipulate specific bits.

The most common pattern is:

```python
1 << i
```

which creates a mask for bit position i.

For example:

```text
1 << 0 = 1
1 << 1 = 2
1 << 2 = 4
1 << 3 = 8
```

Using masks we can:

Check a bit:

```python
num & (1 << i)
```

Set a bit:

```python
num | (1 << i)
```

Clear a bit:

```python
num & ~(1 << i)
```

The key idea is:

**A bit mask lets us manipulate individual bits efficiently.**

## PPT 5 — XOR Pattern: Single Number

One of the most famous bit manipulation problems is Single Number.

The problem says:

Every number appears twice except one.

Find the unique number.

The solution is surprisingly simple.

XOR all numbers together.

Why does it work?

Because:

```text
x ^ x = 0
```

Every duplicate cancels itself.

For example:

```text
4 ^ 1 ^ 2 ^ 1 ^ 2

= 4
```

Everything disappears except the unique value.

The key idea is:

**XOR naturally removes pairs of identical values.**

## PPT 6 — Power of Two and Counting Bits

Another important pattern uses:

```text
n & (n - 1)
```

This operation removes the lowest set bit.

For example:

```text
1000
0111
----
0000
```

This immediately gives us a Power of Two solution.

A power of two contains exactly one set bit.

So:

```python
n > 0 and (n & (n - 1)) == 0
```

We can also count bits efficiently by repeatedly removing the lowest set bit until the number becomes zero.

The key idea is:

**n & (n - 1) removes one set bit at a time.**

## PPT 7 — Missing Number and Hamming Distance

Bit manipulation also solves many array problems.

For Missing Number:

We XOR all indices and all values.

Every matching value cancels.

The missing number remains.

For Hamming Distance:

We first XOR the two numbers.

The XOR result contains ones exactly where the bits differ.

Then we count the set bits.

The key idea is:

**XOR converts comparison problems into counting-bit problems.**

## PPT 8 — Bitmask and Subset Generation

Bitmasking becomes very powerful when dealing with subsets.

Suppose we have:

```text
[a, b, c]
```

There are:

```text
2^3 = 8
```

possible subsets.

We can represent each subset as a binary number.

For example:

```text
000 -> []
001 -> [a]
010 -> [b]
011 -> [a,b]
100 -> [c]
```

Each bit tells us whether an element is included.

This creates a very elegant subset-generation solution.

The key idea is:

**A bitmask can represent a complete subset using a single integer.**

## PPT 9 — State Compression

One of the most advanced uses of bit manipulation is state compression.

Instead of storing:

```text
visited = {0, 2, 3}
```

we store:

```text
1101
```

as a single integer.

This technique appears in:

* Traveling Salesman
* Assignment Problems
* Bitmask DP
* Graph Search with Small State Space

A set becomes an integer.

Checking membership becomes a bit operation.

This is both memory-efficient and fast.

The key idea is:

**Bitmasking compresses complex state into a compact binary representation.**
